
# Java Web & REST API Development

## Project Title
User Management REST API using Spring Boot

## Objective
To develop a REST API using Java and Spring Boot for managing user information through CRUD operations.

## Technologies Used
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman

## Project Features
1. Create a new user.
2. Retrieve all users.
3. Retrieve a user by ID.
4. Update user information.
5. Delete a user.
6. Database connectivity using MySQL.
7. Input validation and exception handling.

## Architecture
- Controller Layer
- Service Layer
- Repository Layer
- Entity Layer

## API Testing
REST API endpoints will be tested using Postman.
